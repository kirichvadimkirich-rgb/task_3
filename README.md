# task_3
# Проект автоматизации UI-тестирования Stellar Burgers

Данный проект содержит автоматизированные UI-тесты для веб-приложения Stellar Burgers  
(https://qa-stellarburgers.education-services.ru/).

Документация API (для контекста): [ссылка на PDF](https://code.s3.yandex.net/qa-automation-engineer/python-full/diploma/api-Stelar_Burger_10.25.pdf?etag=3584917d935c90b69cb3ffaff58d4f34)

## Покрытые тесты

### 1. Восстановление пароля
- переход на страницу восстановления пароля по кнопке «Восстановить пароль»
- ввод почты и клик по кнопке «Восстановить»
- клик по кнопке показать/скрыть пароль делает поле активным (подсветка)

### 2. Личный кабинет
- переход по клику на «Личный кабинет»
- переход в раздел «История заказов»
- выход из аккаунта

### 3. Основной функционал
- переход по клику на «Конструктор»
- переход по клику на «Лента заказов»
- клик на ингредиент – открывается всплывающее окно с деталями
- всплывающее окно закрывается кликом по крестику
- при добавлении ингредиента в заказ увеличивается каунтер данного ингредиента
- залогиненный пользователь может оформить заказ

### 4. Лента заказов
- клик на заказ открывает всплывающее окно с деталями
- заказы пользователя из раздела «История заказов» отображаются на странице «Лента заказов»
- при создании нового заказа счётчик «Выполнено за всё время» увеличивается
- при создании нового заказа счётчик «Выполнено за сегодня» увеличивается
- после оформления заказа его номер появляется в разделе «В работе»

## Требования к окружению
- Python 3.8+
- Google Chrome (последняя стабильная версия) + chromedriver (соответствующей версии)
- Mozilla Firefox (последняя стабильная версия) + geckodriver
- Для Allure: установленная Java (JDK)

## Установка драйверов (без webdriver-manager)

### Chrome
1. Скачайте chromedriver с [chromedriver.chromium.org](https://chromedriver.chromium.org/)
2. Поместите в папку, которая добавлена в `PATH`
3. Проверьте: `chromedriver --version`

### Firefox
1. Скачайте geckodriver с [github.com/mozilla/geckodriver/releases](https://github.com/mozilla/geckodriver/releases)
2. Поместите в `PATH`
3. Проверьте: `geckodriver --version`

## Установка зависимостей

## Allure-отчёт
После выполнения тестов сформируйте отчёт:
allure serve allure_results

Сформируется HTML-файл, откроется веб-сервер Allure, и в браузере появится вкладка с результатами тестов.

Особенности
Тесты запускаются в двух браузерах: Google Chrome и Mozilla Firefox (кроссбраузерность).

Параметризованная фикстура browser автоматически прогоняет каждый тест в указанных браузерах.

Тестовые пользователи создаются через API и автоматически удаляются после каждого теста (фикстура create_user_and_login).

Для создания заказов в тестах используется API (фикстура create_order_api), что обеспечивает стабильность и скорость.

В Allure-отчётах отображаются пошаговые действия,информация о текущем URL, что упрощает отладку.

Все локаторы вынесены в отдельный пакет locators, страницы реализованы по паттерну Page Object Model (POM).

Тесты независимы друг от друга, используют явные ожидания (WebDriverWait).
